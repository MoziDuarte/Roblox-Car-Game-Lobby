This a BETA version for a Car Game lobby

This concept is supossed to be fully customizable and adapted to your own likings/preferences

Features:
- Interactive UI elements
- Cutscenes showcase
- Realistic lightining/building
- Environment Interactive Music Playlist
- Garage system containing:
   - Fully modular category and car lists
   - math logic converting car stats (max speed, accel, etc) into percentage
   - Tweening work between car selection screen and car stats screen
